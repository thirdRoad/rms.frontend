# rms.frontend

## Project Setup

```sh
npm install
```

This also installs the pre-commit hook, which formats and lints staged files on every commit.

### Compile and Hot-Reload for Development

```sh
npm run dev
```

### Compile and Minify for Production

```sh
npm run build
```

### Lint and fix with [oxlint](https://oxc.rs/) and [ESLint](https://eslint.org/)

```sh
npm run lint
```

### Format with [Prettier](https://prettier.io/)

```sh
npm run format
```

### Check formatting and lint without fixing (same as CI)

```sh
npm run check
```
